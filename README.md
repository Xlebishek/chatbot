# AI-Ассистент СПбГУ (RAG & Multi-Agent)

Интеллектуальный чат-бот с поддержкой RAG (Retrieval-Augmented Generation), разработанный для ответов 
на академические вопросы и работы с документацией СПбГУ.

## Технологический стек
- **Язык**: Python
- **Веб-фреймворк**: Streamlit
- **LLM**: GigaChat (через API)
- **Векторная база данных**: Qdrant
- **Эмбеддинги**: `sentence-transformers`
- **Архитектура**: Multi-Agent System с RAG-компонентами

---

## 📂 Структура проекта

### `agents.py`
Основной файл, содержащий логику, инструменты агентов-помощников.

#### Инициализация и компоненты
- **RAG-компоненты**: Глобальные переменные для управления языковой моделью и векторной базой.
- **LLM модель**: Инициализация **GigaChat** с использованием API-ключа.

#### Инструменты агентов (Tools)
- `arxiv_search()` — поиск научных статей по заданной теме *(требует запрос на английском языке)*.
- `schedule()` — поиск расписания преподавателя по его имени.
- `rag_search()` — семантический поиск информации в документах СПбГУ через векторную базу.
